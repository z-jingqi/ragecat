# Rage Cat

Godot 4.6.3 Standard 桌面 2D 生存原型，Compatibility 渲染器，无需 .NET、第三方素材或网络。导入 `project.godot` 后 F5，或 `godot --path .`。

## 操作

- WASD 移动，Space 冲刺，Esc 暂停；自动瞄准和射箭。F12 截图写入用户数据目录。
- Endless 拾取经验后三选一。Practice Lab 可设置等级、生成敌人、切换 AI、调整速度并重置。
- 主菜单与暂停菜单可切换普通/远程敌人血条，默认开启；Boss 血条始终显示。血条与音效开关保存到 `user://display_settings.cfg`，不保存构筑或练习状态。
- UI 支持 English 与简体中文原地切换，菜单、HUD、升级、技能与提示均完整本地化，内置 OFL 授权的 Noto CJK 字体子集。当前一个角色、一把弓；内置原创合成音效，无局外成长、联网或手柄支持。

## 元素附魔与伤害

四种附魔为火、雷、冰、暗，同一时刻一种。附魔 Lv1/2/3 只增加 5/10/15 元素伤害，不自动获得特殊效果。其他元素卡仍可出现：切换继承共享附魔等级和已取得的元素弓技能等级，不额外升级；技能 Lv0 切换后仍无技能。选择当前类型才提升附魔等级。满级仍可切换其他类型。

- Weapon Power 固定增加 5/10/15 基础武器伤害；Sharp Claws 全局增加 20/40/60% 总伤害。
- B = (弓基础伤害 + 固定武器增益) × (1 + 全局百分比)；E = 当前附魔伤害 × (1 + 全局百分比)。
- B、E 同时承受连珠、侧箭、分裂和一次性穿透保留系数，再共享一次暴击判定。一次命中只扣一次总生命、触发一次命中事件。
- 连珠 Lv1/2/3 每轮 2/3/4 次齐射，每箭保留 60/45/38% 伤害；扇射侧箭保留 55%；分裂两碎箭保留 30/45/60%。碎箭不能暴击、再次分裂或穿透；火技能允许碎箭爆炸，雷技能允许碎箭连锁；冰技能允许碎箭叠霜及碎冰；暗技能不触发。
- 敌人头顶分别显示基础与元素伤害。普通基础白色，暴击基础较大金色；元素以 F/L/I/D 标识并按类型着色，暴击标记 CRIT。过量伤害按 B/E 比例分配实际生命损失，显示至两位小数；没有第三个重复总伤害数字。范围/连锁仅显示非暴击元素伤害。

## 独立元素弓技能

需当前附魔后另选技能，均最高 Lv3，默认规则如下。旧毒、流血及相关组合已移除；连珠、扇射、长弓仍是独立射击改造。

- 爆燃箭（火）／灼伤：每支主箭和碎箭首次有效命中在实际接触点爆炸，半径 70/85/100，造成该箭暴击前 E 的 100/150/200%。不伤害初始目标，无暴击、击退或递归触发。致死首击也爆炸，之后立即消失，穿透升级在该形态暂不生效但等级保留。连珠与扇射每支箭独立爆炸；主箭首击先生成碎箭，碎箭继承剩余射程、忽略源敌人的直接碰撞，爆炸只排除自身首击目标，仍可伤害原主箭目标。碎箭爆炸使用自身暴击前 E，连珠/侧箭/分裂系数各仅一次，无递归分裂；未命中即耗尽射程不爆炸。直接命中和爆炸命中（均含碎箭）各有 20/30/40% 几率灼伤存活目标，持续 3 秒，每秒造成来源箭暴击前 E 的 20/30/40%。爆炸倍率不放大灼伤，连珠／侧箭／分裂／穿透保留系数只算一次。每敌人只有一份灼伤；重触发只刷新剩余时间，保留原 DPS 与跳时钟，不即时追加伤害。每 0.25 秒游戏时间结算，最后不足一跳按实际时间补算；只造成火 E，不暴击、不递归，实际伤害与击杀仍计入统计及经验。
- 闪电箭（雷）／感电：每次有效直接命中（包括每次穿透命中与碎箭命中）从当次初始敌人位置，逐跳选择 140 范围内最近的 2/3/4 个额外不同目标；等距离以实例 ID 决定。各受该次命中暴击前 E 的 100%，其中穿透保留率、连珠/侧箭/分裂系数各应用一次，不恢复主箭伤害。不暴击、不击退、不眩晕、不再次触发连锁或分裂。每条连锁独立去重并排除自身初始目标；不同直接命中产生的连锁可再次伤害同一个敌人。碎箭仍不再次分裂。直接和连锁命中各有 20/30/40% 几率施加感电，持续 2 秒，后续受到的元素伤害增加 10/15/20%，基础 B 不变。触发该状态的那次命中不追溯增伤；重触发只刷新时间，保留原易伤快照。易伤只在受击目标的伤害入口结算一次，不污染连锁／爆炸／灼伤的来源 E。感电本身没有伤害或攻击削弱。
- 寒冰箭（冰）／冻伤：每次直接箭命中（含穿透、连珠、扇射与碎箭）附加 20% 减速 2 秒与一层寒霜；3 层冻结 0.65/0.8/1.0 秒并清空层数。冻结停止自身移动，但不取消远程攻击、接触伤害或外部击退。下一次直接箭命中先消耗冻结，然后整份 B+E 翻倍；第三次叠满的命中不翻倍。碎冰不再叠霜或刷新减速；可以与一次正常暴击乘算，碎箭仍不能暴击。寒霜整体在最后合法叠层后 2 秒过期；自然解冻和碎冰均开始 2 秒叠霜免疫。Boss 不冻结，保留 10% 减速；5 层形成可见冰印记，下一次直接命中翻倍并消耗印记，该次不叠层，随后可开始新循环。印记与叠层窗口各 2 秒，无 Boss 解冻免疫，不改变冲锋／落石／AI。范围、连锁、持续伤害及引力不能叠霜或碎冰。
- 暗影箭（暗）／引力：技能 Lv1/2/3 将弓变为唯一一支慢速直线引力箭（180/140/110 像素/秒），漩涡随箭头移动，不追踪，不留下固定场。暗附魔且技能 Lv0 仍为普通箭。箭按弓射程、边界或 8 秒安全寿命消失；直接命中不会销毁引力箭。天然无限直接穿透，同一敌人每箭至多命中一次，所有直接 B+E 命中保留 100% 伤害。穿透升级暂不生效但等级保留；无技能的暗附魔、雷/冰等普通形态恢复原有限穿透及保留率。HUD、卡片与练习面板标明当前有效穿透规则。
- 引力箭消失后才开始 0.5 秒间隔，攻击速度缩短为 max(0.3, 0.5 / (1 + 攻速增益))；飞行期间不预充、不积攒连珠。切换元素、变更等级、清场不能绕过剩余间隔；完整练习重置/新局重新开始。
- 引力外圈 140/160/180，伤害内圈 50/65/80；内圈每秒造成 E × 1/1.3/1.6，按 0.2 秒游戏时间结算。连续在圈内的完整时间量子才造成伤害，不暴击、击退、分裂或递归触发，不包含 B。逐敌累计实际在内圈的暴露时间，离开保留不足一跳的余量，再进入无免费即时伤害；箭移动使用线段穿越内圈的实际时长，完整跳即使在该步末离开也结算；源消失丢弃不足一跳的余量。暂停停止全部时钟。
- 普通/远程敌人质量默认 1，Boss 默认 10；质量降低加速度和持续吸引速度。敌人自身 AI 与平滑引力速度在一次位移中相加，边界钳制，不瞬移。Boss 非冲锋阶段可被弱拉动；冲锋预警及冲锋期间免疫引力，不改变锁定路径、警告或攻击。
- 在有效外圈内即视为受引力影响，与可见速度无关；此敌人的普通接触伤害被抑制，离开/源消失后保留 0.1 秒接触宽限。其他敌人、远程弹、落石和 Boss 冲锋仍能伤害玩家。Boss 冲锋免疫优先于残留宽限，不提供全局无敌。
- 引力模式保留所有升级投资：连珠 Lv1/2/3 转为持续伤害 +15/30/45%，扇射转为外圈 +10/20/30%，分裂转为内圈 +10/20/30%，不额外生成箭、侧箭或碎箭，也不叠加原连珠/侧箭/分裂伤害代价。长弓只延长射程，不加飞行速度；击退转为有上限的吸引强度，直接命中不向外击退。攻击速度仅改变箭后的间隔，不改变持续伤害跳频。切换其他元素后恢复普通改造。卡片与练习提示显示当前模式的转换和资源数值。

切换元素时清除己方在途箭/碎箭、旧元素效果、灼伤、感电与敌人冰状态，取消待发连珠；保留普通攻击计时与引力箭后的剩余间隔。敌人、敌方子弹、Boss 预警、生命、经验及通用升级不受影响。暂停冻结游戏计时；死亡、重启和练习清理正确回收效果。

## 命中反馈与声音

- 有效直接箭命中使用 0.05 秒的短促白色提亮、方向性碎屑和敌人局部移动顿挫；每敌人 0.2 秒触发间隔，期间不刷新，不暂停玩家、箭或世界。爆炸／连锁只有较轻的 0.025 秒移动顿挫与碎屑，不触发白色提亮；灼伤／引力持续伤害只有较小的带类型数字和持续状态表现，不反复顿挫或播放命中重音。高频攻击最大持续移动中断占比为 25%。
- 顿挫仅影响 AI 位移，不是攻击眩晕，不改变接触伤害、远程攻击计时或无敌规则；与冻结重叠而非叠加延长。Boss 仅有短促视觉反馈，绝不暂停或改变冲锋／落石承诺。普通击退改为 0.08 秒内快速减速位移，基础仍为 45 像素；新击退替换剩余位移，不累加无界速度，外力与 AI／引力由敌人物理统一积分并限制在边界内。Boss、木桩免疫与暗技能的击退转换不变。
- 暴击略增加金色碎屑；爆燃箭呈向外扩散，灼伤有细环火苗；闪电箭依次显示连锁路径及分支，感电持续黄弧；寒冰箭显示霜层、结晶、Boss 冰印与碎冰裂纹／冰片；暗影箭保留移动漩涡和双圈，并有向内流动的细线。没有屏幕震动或全局时间停顿。
- 击杀立刻结算生命、目标与经验；独立轮廓快照仅做 0.15 秒缩小淡出，不保留活动敌人。共享碎屑节点上限 48、死亡快照上限 12，每节点最多 20 片；原有伤害数字与技能范围表现也分别保留节点上限，饱和只丢弃表现，绝不丢失伤害。
- 原创短音效区分射箭、普通命中、暴击、击杀及四种元素；连锁每次事件只播放一次，灼伤和引力每跳不播放重音，暗漩涡仅生成时播放短包络声，不使用永久循环。固定 6 声部池（硬上限 8）与各音效冷却限制重复声音，局部随机音高不会扰动战斗随机流；暂停、重置、切换元素和离开场景停止声音。主菜单／暂停菜单的 Sound effects 开关持久保存，构筑不保存。

## 配置与测试

- `resources/cat.tres` 与 `resources/bow.tres`：角色、基础战斗与武器参数。
- `resources/upgrades/*.tres`：24 项升级的等级与类别；卡片直接显示所选等级效果，无前后对比。
- `resources/elements/*.tres`：元素技能半径、系数、链距离、状态时序、颜色等；暗元素内的 GravityDefinition 独立配置飞行速度、双圈、伤害、质量相关吸引参数、间隔与升级转换表。
- `resources/settings/`：竞技场、敌人、生成节奏、Boss、练习预设等。伤害数字尺寸/颜色/偏移通过 Arena Definition 的 Damage Feedback Resource 配置。`resources/feedback/hit_feedback.tres` 配置顿挫、击退包络、白色提亮与碎屑上限；`resources/audio/feedback_audio_default.tres` 配置音效音量、声部、间隔与音高。
- 活跃运行使用验证后的配置快照；输入资源不被战斗修改。元素采用列表/容量结构，当前版本容量固定为一，未实现多元素。

运行全部回归：`bash tests/run_all.sh`。指定 Godot 可设置 `GODOT=/path/to/godot`。受限环境请设置可写 HOME、XDG_DATA_HOME、XDG_CACHE_HOME、XDG_CONFIG_HOME。独立长局脚本支持 `-- --output=/absolute/path/results.json`，生成结果不要提交。

音效由 `python3 tools/generate_feedback_audio.py` 确定性生成；`--check` 只读校验 PCM、样本边界、峰值与混音余量，不写报告。测试关闭前使用短暂音频线程排空，避免快速无界面退出时误报未回收播放引用。

正式导出需匹配的 Godot 4.6.3 export templates，预设输出到 `build/`。仓库仅保留源码、配置、可复用测试与使用说明，不保留报告、运行结果、截图、校验清单、缓存或导出包。数值是初版平衡，不保证所有构筑或长局均衡。


## 中英文与可读性 / English and Simplified Chinese

- 首次启动按系统语言选择：所有中文地区变体使用简体中文，其余语言使用 English。主菜单与暂停菜单的语言选项显示 `English` / `简体中文`；手动选择独立保存，不覆盖音效和血条设置。无效或损坏的语言设置回退到系统语言规则。
- 切换语言原地更新菜单、HUD、练习参数、卡片、提示与伤害文字；不重新开始，不重抽升级，不改变生命、等级、敌人、随机流、暂停状态、技能计时或待发箭。练习场的等级、AI、时间速度和首领参数保持不变。
- `resources/localization/en.po`、`zh_CN.po` 是唯一显示文案目录，由 Godot `TranslationServer` 读取。稳定的翻译键与升级／元素内部 ID 分离；描述中的数值和概率仍来自资源，不在翻译中复制平衡参数。英文技能为 Blazing Arrow、Lightning Arrow、Frost Arrow、Shadow Arrow。
- `TextFit` 按字体实际字形、可用宽度和智能换行规则测量：先换行与增高，超过合理高度才缩字；标题／按钮最低 16 个逻辑像素，正文／说明最低 14 个逻辑像素。仍放不下时滚动查看全文，不继续缩小或省略关键机制。仅在文字或宽度变化时重新测量并缓存结果；伤害数字不按位数动态缩字。
- 当前固定竞技场桌面版需要至少 **1280×800 的可用客户区**，采用 DPI 感知的逻辑像素约定；窗口只向上缩放，不把整套界面缩小到字号下限以下。不能保证带任务栏／窗口边框的 1366×768 桌面容纳此客户区；更小屏幕的响应式竞技场不在本版范围内。菜单与升级卡可纵向滚动；不使用悬浮提示。暂停菜单进入练习控制，聚焦升级名称并确认打开可滚动全文，上下滚动，确认或返回关闭并恢复焦点；退出练习控制恢复进入前的运行或暂停状态。鼠标仍可选用，但不是读取完整说明的前提。
- 执行 `python3 tools/rebuild_ui_font.py` 可从本机已安装且获许可的 Noto CJK 原字体重建小型字体子集，不联网下载。详见字体目录的说明与 OFL 许可。
- `tests/run_all.sh` 在独立临时用户目录执行 39 项既有回归、1 项中英文独立契约与 1 项音频退出时钟契约、1 项控制器导航套件，不读取或改写玩家设置。新增契约覆盖占位符、全字库、资源数值、语言回退、跨进程保存、运行中状态、真实卡片边界及超长文本滚动。

- 控制器交互使用 Godot 语义输入动作：方向导航、确认、返回、暂停；移动支持左摇杆／方向键，冲刺使用独立右肩键，不与确认重叠。本版提供桌面控制器友好的交互，不代表已完成主机平台导出或认证。
