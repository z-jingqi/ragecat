# 接触增强验证 · 2026-11-06

基线：`1e3f04b`，Godot 4.6.3。仅修改单根土锥脚下接触，不改整圈、冰锥、土锥刚性碎裂及其时序。

## 本轮变化

- 五条不等距弯折的地裂，以同种子确定性生成，在55ms破土期间展开。
- 四块大小轮廓不同的土块从根部上抛，刚性转动后落回；不使用矩形砖块动画。
- 地裂与土块保留到残渣消失，不发生0.24秒突然消失的地裂闪断。
- 复用原有岩体、三阶段细屑、材质颜色和透明度；不加入大烟团、闪白或形变。
- 参考方法和许可证沿用 README 与 licenses，未下载或复制外部素材。
