# 确定性单次雷击算法

1. 触发时校验起终点，计算轴向单位向量和垂直向量。段数为 ceil(长度/名义段长)，钳制到 2–64。
2. 首尾严格保留端点。中间节点按轴向均匀分布，加小范围轴向偏移；横向偏移交替变号，幅度由固定种子确定，并乘 sin(πt) 使端点收敛。随机只在触发时执行。
3. 最多四个分叉选择沿主干分布的内部节点，向轴向下游和交替左右伸出。每个分叉只有一个折角，宽度和长度均从属于主干；不递归。
4. 击穿阶段显示比例从零增长到一。分叉在主干到达其根部后才显现；目标点接触短十字仅在击穿完成后出现。
5. 亮峰固定几何；衰减收窄线宽、从亮芯退到边缘色，最后从起点向目标收短。没有逐帧随机、alpha 渐变或整屏曝光。
6. 以低分辨率画布的非抗锯齿线段绘制三层硬色；显示顶点落在像素中心。预览的放大图直接读取同一低分辨率纹理，避免分别绘制导致的栅格差异。
7. 单次结束清空全部折线与分叉。节点复用，上限 65 主干点、4×3 分叉点；不会因反复播放累积历史。

未来移植只需确定性随机数、向量运算、生命周期和像素绘制适配。若要求跨引擎逐像素同种子一致，还需统一 PRNG 与线段栅格化算法；当前仅保证同 Godot 实现可复现。
