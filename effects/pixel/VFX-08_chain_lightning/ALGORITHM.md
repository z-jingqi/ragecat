# 算法

1. 去重并用弱引用保存有限候选集。起点为给定位置，后续起点为上一命中目标当前坐标。
2. 每个跳跃时刻扫描未访问且有效的候选，选范围内最近者，稳定处理同距离；已选择目标立刻标记，杜绝重复回跳。
3. 为该边生成有粗细变化的相关随机折线和少量分叉，保存不可变初始几何。当前端点移动时，把原几何沿轴缩放/旋转到新端点，横向宽度不跟随长度缩放。
4. 时间推进按跳跃边界切分，而不是每帧最多跳一次；大delta同样可遍历全部跳跃。命中通知在击穿完成后发一次，回调重置会被generation标记捕获，停止后续旧逻辑。
5. 子电弧寿命结束即销毁；候选最多128，访问最多12，活动电弧不超过12。所有视觉结束后发finished。
6. 局部火花与演示目标闪色区分。生产组件只发目标事件，真实游戏自行管理伤害和敌人外观。
