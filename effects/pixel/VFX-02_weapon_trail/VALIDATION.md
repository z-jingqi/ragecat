# VFX-02 原型自检记录

2026-11-02；Godot 4.6.3 标准版，Compatibility / OpenGL。此记录属于 **Godot 设计原型**，不代表其他引擎实现或用户视觉确认。

## 已验证

- 17 项实际 GDScript 历史测试：静止不收样/不续时，彻底到期后也不重新种点；旋转与反转；停止后清尾；瞬移/大角度跳变断开；2,000 次输入下固定 64 槽复用；实时 cap 裁剪；平移旋转世界端点；无效 dt / 坐标 / 配置；直线、斜向、轴向实际端点采样。
- 21 项预览状态测试：暂停、精确 1/60 秒单步、速度、反向、静止、瞬移、3 个真实 JSON 预设、透明模式、最小寿命/容量、完整重置、标签同步、相机与两种倍率一致、非有限视觉参数回退；固定朝向直线/斜向平移与曲线+旋转。
- 7 项数学/配置契约测试，以及纯数学源 → Godot Shader 与配置副本同步检查。
- 原生 GPU 实际运行：1× 游戏尺寸与 2× 像素细节均清晰，无 AA 黑边或模糊光晕；实际点击 Pause、+ Frame、Turn、Speed、Play、Stop，并逐项选择 Straight translation、Diagonal sweep、Curve + rotation；观察到固定朝向平移也实际留下扫掠历史。停止后只留下宿主演示线，拖尾完全消失。
- 引擎 MovieWriter 实际渲染录制：640×360，60 fps，960 帧，16 秒。序列为旋转基线 → 固定朝向直线平移 → 固定朝向斜扫 → 曲线+旋转 → 1.7× 速度与反向 → 停止并清尾 → 瞬移断开 → 恢复基线。不是截图拼接、精灵图集重放或离线重绘。
- 视频经 H.264 编码并核对尺寸、帧率、帧数与时长；录制采样帧核对各轨迹与停止清空状态。视频存于独立交付位置，不将生成视频或缓存放进源码目录。

## 边界

- 当采样速度过高或把 max_samples 调得过小，容量上限会先于 lifetime 截断最旧记录，这是明确的有界预算，不保证任意参数下都保留完整寿命。
- 本项是刀刃扫掠面，不是固定宽度的中心线拖尾；严格沿零厚度刀刃轴向直刺时扫掠面积为零，不虚构横向宽度。
- 采样只能忠实保留游戏实际提供的端点；不会虚构极低更新率下的曲线路径。单步大于 120° 的旋转安全断开。
- 预览场景限制最高 60 fps，逻辑仍按实际秒差推进。正式采样类不设置或依赖全局帧率。
- 使用者应按游戏像素密度和武器尺寸调参；此演示不包含伤害、碰撞或完整角色资源。
- **Unity 实现暂停，不在本项交付；未进行 Unity 编译或运行验证。** 当前仅等待用户对设计与预览的视觉反馈。
