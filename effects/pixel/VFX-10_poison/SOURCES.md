# Visual references

- https://particlefx.studio/effects/plague-cloud — inspected page, downloaded poster and 8-moment strip (0–2.63 seconds). Studied stable footprint, low rolling gas, staggered rising bubbles and sparse wisps. The HD reference uses additive glows; this implementation intentionally uses hard limited pixel colors.
- https://particlefx.studio/posters/pixel-art-vfx/pixelPoisonCloud.webp — inspected public pixel poison poster for stepped lobes, bright crests and dark internal creases. A single poster is not evidence of animation timing.
- https://particlefx.studio/effects/creeping-poison-gas-top-down — read layer description for ground-hugging gas versus ascending smoke.

Reference downloads remain outside the repository. No ParticleFX asset or source was copied into production. All effect geometry is original procedural code; no third-party texture license is required by this component.
