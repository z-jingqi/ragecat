# Engine-neutral specification / 中立算法

状态与像素绘制完全分离；以下数学不依赖 Godot API，但源文件并不能直接导入其他引擎。

## 输入和状态

每次接收 `dt > 0`、连续世界位置 `p`、真实速度 `v`。单位为逻辑像素、秒。当前 Godot 适配采用 +X 向右、+Y 向下；其他引擎只在边界转换坐标，不修改公式语义。非法非有限输入不推进状态。

保留头部位置、单位朝向、年龄、独立内流时间、退出时间、当前尾长，以及最多 96 个真实位置。与上次保留点间隔至少 0.75 px 才新增。删除累计弧长超过 `tail_max+2` 后的多余历史；不合成不存在的历史。单次位置移动超过 96 px 时清空历史。

## 速度响应

运动中：

```
s = clamp(length(v) / speed_reference, 0, 1)
L_target = lerp(tail_min, tail_max, s)
L = lerp(L, L_target, 1 - exp(-dt / speed_response))
```

速度接近零时 `L_target=0`。这是时间常数，不是每帧插值比，30 / 60 / 144 FPS 的固定输入结果相同。当前朝向来自真实速度，零速度保留上次朝向。

## 生命周期

进入阶段 `enter=min(age/0.025, 1)`。寿命结束或 `stop` 后记录退出年龄；`exit=max(1-exit_age/0.09,0)`。总包络 `e=enter*exit`；缩短尾并缩小头，在 90 ms 内清空，不产生长残余。立即清除则同一调用直接释放历史。寿命跨越时将本次 `dt` 超出的部分计入退出年龄，避免大帧导致无限停留。暂停冻结全部计时及输入采样；重置清理所有状态。

## 圆头和连贯短尾

头半径 `r=head_radius*e`。按从最新位置向后的历史累计弧长 `s`，尾部局部半径：

```
w(s) = r * max(0, 1-s/(L*e))^0.8
```

逐段求片元到历史线段的最近点，线性插值得到该点累计弧长和局部半径；并集由 `distance_to_segment-w(s)` 与头部圆 `length(local_p)-r` 的最小有符号距离产生。历史按 `L*e` 截断，因此尾长是路程，不是头尾直线距离。转向时尾部自然保留前一段方向，不作为静态三角形跟着旋转。

身体和边缘为不透明离散色阶，轮廓外 alpha=0；不使用外圈或柔化。芯部是前导头中的小透镜亮块，以及内部沿尾向移动的短亮片：

```
phase = fract((s-flow_time*30)/10)
sliver = phase in [0.69,0.92]
```

亮片仅在轮廓内部且离边缘至少 1.15 px 的窄带显示。内流以 30 px/s 向尾端走，头部核心仅作 5% 以内的局部形变，且受 `flow_strength` 调节。整体不反复放大缩小，不将高频闪烁当作运动。

## 像素绘制

只在绘制时取 `floor(local_fragment)+0.5`，显示头位置取整；模拟世界位置、速度、历史不取整。4×诊断仍按原始 1 px 逻辑栅格采样后整数放大，因此不是更细的第二种效果。相机只影响显示位置。Shader 用显式内流时间 uniform，而非不服从暂停的全局 `TIME`。

## 预览运动的边界

演示控制器以固定 1/120 s 步长积分，目标偏角限于 ±0.68 rad，转速上限 1.6 rad/s。它只是制造合法的测试输入；未来游戏应替换整个演示控制器，保留输入/生命周期契约。没有追踪敌人、自动选目标或伤害判定。
