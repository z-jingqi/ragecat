# 引擎中立算法

1. 使用固定种子生成扁椭圆散落位置，按随机化角度分布。抛落横移采用ease-out，竖直高度为sin(pi·u)·height；到时精确落到ground。
2. 停留的上下幅度仅1像素，渲染位置取整数。停留超时回收，不触发抵达。
3. 接收吸附指令后从35px/s加速至上限。每个固定步根据当前目标重算单位方向，沿该方向移动。距离不大于本步位移/2px门限时直接置于目标，保证不越过目标后振荡。
4. 保存至少相隔1像素的路径点，按弧长裁剪并限制48点。尾迹不驱动物品运动；实时目标不是固定二次曲线终点。
5. 到达状态只进入一次，发出唯一id通知并清轨迹，然后画短四向抵达闪点，时限后回收。目标无效在吸附阶段转为停留，不发通知。
6. 核心不维护经验数值。未来接入其他引擎需要重写绘制与宿主接口，状态规格/参数可以复用，不能直接导入Godot脚本。
