# 独立路径线的中立规格

## 和已有两种效果的区别

此处是**单个实体尾端锚点的历史路径**，不是武器根/尖两个端点扫过的面，也不是圆形能量头与尾共同生成的发光轮廓。实体与路径在同一Shader绘制但使用独立遮罩、宽度和调色板；关闭路径不改变实体。

## 连续状态与采样

输入为秒、逻辑像素位置、逻辑像素/秒速度；Godot适配采用+X向右、+Y向下。位置、速度、历史和时间保留浮点精度。仅绘制时将片元采样到整数像素中心，并将显示位置取整。

以真实速度归一化取得方向；箭矢/飞刀从输入刃尖位置向后偏移20/18 px得到尾部锚点。间距至少0.65 px才写入一个带时间戳的历史点。新到旧遍历，剔除超过保留秒数、超过`length_max+2`弧长或超过128点的多余记录。点与时间数组长度必须始终一致。

位置跳变阈值96 px在原始输入上判断，跳变不插值、不接旧历史。更换实体类型/比例同样清空历史，避免从旧尾端拉线到新尾端。输入NaN/Infinity不会推进状态。

## 按实际速度响应

```
speed01 = clamp(length(velocity)/speed_reference, 0, 1)
target_length = lerp(length_min, length_max, speed01)
L = lerp(L, target_length, 1-exp(-dt/speed_response))
```

静止时目标为0。绘制路径按累计真实弧长裁剪到`L`，而不是按起终点直线距离裁剪。保留时间不足时，尾只画真正存在的部分。

## 像素路径轮廓和到期

每个绘制片元对各历史线段求最近点，插值得到累计弧长`s`和时间戳。`life=clamp(1-(now-stamp)/history_seconds,0,1)`。

```
radius = trail_width/2 * max(1-s/L,0)^taper * life^0.45
```

在最后细尖之外，对仍存活且半径>0.16 px的段使用至少0.54 px覆盖，避免像素化斜线中段无意义断裂。透明度按3个离散档递减；轮廓外透明，无柔边、Bloom、内流或随机亮斑。有限的两级路径色与实体金属/木质色独立。

Stop后不再采样和移动实体；已记录点留在原世界位置，随时间收细、减淡和删除。立即停止则同调用清空。寿命边界落在一个大`dt`中时，将正常连续位移插值到精确寿命时刻，并以对应时间戳保存最后锚点，再进入停止。大帧余量仍参与历史过期；瞬移与寿命同时发生时仍先断开路径。

## 演示运动不属于游戏逻辑

演示以1/120秒固定步长积分。直飞朝向与长轴始终一致；转向目标为±0.38 rad内的缓动偏角，最大转速1.2 rad/s。没有目标搜索、伤害或碰撞。宿主游戏应替换演示控制器，提供真实位置、速度和停止/命中事件。

Shader绘制用Godot官方[CanvasItem语言/API](https://docs.godotengine.org/en/4.6/tutorials/shaders/shader_reference/canvas_item_shader.html)，没有导入第三方美术或效果代码。规格可供未来其他引擎重新实现，但当前没有Unity组件、移植器或正式目标引擎验收。
