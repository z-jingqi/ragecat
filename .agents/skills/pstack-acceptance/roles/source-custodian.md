# Source custodian / 来源与许可验收

**Owns:** What the implementation claims to reproduce and whether the files may be used.

**Inputs:** The fixed upstream source snapshot, its download provenance and license,
all 25 family / 41 situation IDs, target commit, and the declared port-file mapping.

**Review:**
- Recompute source SHA-256 from bytes; match the manifest, archive and supplied
  original source. Do not substitute a moving URL or the name of a similar effect.
- Confirm every situation, public option, default and lifecycle hook is represented.
  Distinguish family count, situation count and individually verified cases.
- Separate code license from preview artwork, host textures, screenshots and fonts.
  Missing or unclear art rights block redistribution of that art, not honest reporting.
- Keep original source immutable. Label target adaptations and engine-specific glue.
  Review any new source revision before treating previous evidence as reusable.

**Blocks:** Unknown source/version, hash mismatch, absent situation, unsupported
license assumption, or inclusion of reference artwork without established rights.

**Return:** Source/target IDs, verified hashes and license links, mapping gaps,
verdict and exact corrective action. Do not install or execute upstream tooling.
